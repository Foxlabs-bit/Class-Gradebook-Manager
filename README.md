#### Class Gradebook Manager ####

## What it is ###
Class gradebook manager (CGB) is a python focused grade organizer for both students and teachers. It features many elements like:

- Show all scores
- Show class average
- Grade in letter format
- Highest and lowest scores
- Count passing students
- Settings option for customizability (Coming soon in actual release)

## How to use locally ##
** This will change over time when the project advances **

# If you just want the python script assuming you have python installed#
0. install python and run this command :pip install colorama
1. Open the github page for the project here: https://github.com/Foxlabs-bit/Class-Gradebook-Manager
2. Find the file named "Class_gradebook_manager_main.py"
3. Download that file and save it somewhere which you know where it is. I use desktop
4. Open a new terminal window
5. Type "cd Desktop"
6. Type "python3 class_gradebook_manager_main.py"
7. It will open directly in your terminal window to use
